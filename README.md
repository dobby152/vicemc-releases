# ViceMC – vydání

Stáhni **`ViceMC-Launcher.exe`** (47 MB), spusť ho a stiskni **Instalovat**. Launcher stáhne hru a sám ji aktualizuje.

- Odkaz ke stažení: https://github.com/dobby152/vicemc-releases/raw/main/ViceMC-Launcher.exe
- Windows může při prvním spuštění zobrazit varování SmartScreen (soubor není podepsaný): *Další informace → Přesto spustit*.
- Server: `threw-balcony.tun.ply.gg:9669` (je předvyplněný v launcheru; běží jen, když je zapnutý počítač hostitele).

Složka `files/` a `manifest.json` jsou data pro launcher. Needituj je ručně.
